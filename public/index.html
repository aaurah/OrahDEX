OrahDEX

A backend API for decentralized exchange (DEX) functionalities, supporting trading, liquidity pools, and token swaps.

Project Overview

OrahDEX is a Python-based backend service focused on providing decentralized exchange capabilities including token trading, liquidity pool management, and price queries. The primary framework is lightweight, likely Flask or FastAPI (given the Python dev command). The project consists mostly of server-side code with no frontend UI.

Technology Stack

  • Language: Python
  • Framework: Possibly Flask or FastAPI (typical for Python APIs)
  • Package management: pip with requirements.txt
  • API style: RESTful JSON-based endpoints
  • No frontend framework: This is a backend-only API

API Endpoints

The backend exposes the following example endpoints for decentralized exchange operations:

GET /api/markets
Lists available trading markets, with tokens and prices.
POST /api/trade
Submits a trade order (buy/sell) for a token pair.
GET /api/liquidity-pools
Returns information about liquidity pools and their token reserves.
POST /api/swap
Executes a token swap transaction.
GET /api/prices/{token}
Fetches latest price data for a given token.

* Actual endpoints and parameters depend on backend implementation.

How to Run Locally

  1. Clone the repository.
  2. Install dependencies with pip install -r requirements.txt.
  3. Start the server by running python main.py.
  4. The API will be accessible at http://localhost:8000/ or the configured port.
